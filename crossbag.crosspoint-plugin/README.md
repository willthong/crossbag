Crossbag

Crossbag pulls your unread wallabag articles onto this device as EPUBs.

Setup (once)

Open the device web UI, run the Crossbag setup wizard, and enter your
wallabag server URL plus the API client ID, client secret, username, and
password. The wizard saves them to config.json.

Daily use

Open the Crossbag catalog on the reader, browse your unread articles newest
first, and pick one. It downloads to /Wallabag as an EPUB.
